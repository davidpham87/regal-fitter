# Use LSP

Start a clojure-lsp to navigate the codebase and search. Use /clojure-eval as
well to help you to validate code.

You don't need to execute npm run build to check if things work. There is a
watch process that is already lunch and do hot code reload.

Use /clojure-eval to connect to the cljs-repl and reload the namespace that you
modified and execute app.core/reload!
